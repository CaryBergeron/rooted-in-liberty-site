# Rooted In Liberty website

Static site for the Rooted In Liberty Library: free sampler signup (25 Lessons From George Washington), book shelf, about, FAQ, privacy, and thank-you pages.

- `index.html` home and signup
- `thank-you.html` page shown after signup
- `privacy.html` privacy policy (needed for Meta ads)
- `styles.css` brand styles (navy #242567, red #b2091a, cream #f8f2d8; Playfair Display, Domine, Montserrat)
- `assets/` logos from Dropbox `01 Brand/Logo` and the Library seal

Signups post to Mailchimp through the `FORM_ACTION` setting at the bottom of `index.html`.
Hosted on GitHub Pages from the `main` branch.
